OPEN THE BLACK BOX

What Jev actually sees

Four cameras produce idealized detections with range, field-of-view and vehicle-occlusion limits. The server sends this state and five independent questions to Jev. No rendered images are sent. Lane choice selects which speculative speed answer is applied.

Collision detection, physics, a 1.8-second stale-command brake, and lifecycle resets run in code. There is no hidden obstacle-avoidance controller for the cyan car.
